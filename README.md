# ESP32 Flasher & Encryption Manager

A powerful desktop tool for programming ESP32 devices with hardware-based flash encryption. Generate and control your own encryption keys, burn security fuses, and protect your firmware from unauthorized access—all in one intuitive interface.

**Key Features:**
- 🔐 Hardware-accelerated flash encryption
- 🔑 User-controlled encryption keys (you keep the key file)
- 🔒 One-time programmable (OTP) security fuse management
- 📦 Multi-file flashing (bootloader, partition, firmware)
- 🔄 Smart encryption detection and auto-adaptation
- 🛡️ PlatformIO and Arduino compatible

**Perfect for:**
- Protecting intellectual property in production devices
- Secure IoT deployments
- Developer security testing
- Multi-device production with controlled key management

Built with Qt 6.11.0 and powered by Espressif's esptool, espefuse, and espsecure.
